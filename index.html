Vendas de Viagens

Sistema mobile de vendas e gerenciamento de pacotes de viagem.

Funcionalidades

  • Gerenciamento e compra de pacotes de viagem
  • Sistema de compra e conversão de dinheiro e milhas com Conversão de Cashback de milhas por compra
  • Criação de API REST própria e integração com API REST externa
  • Carteira simulando valores em dinheiro, milhas e histórico com data de depósitos e pagamentos por pacote do usuário.

Tecnologias Utilizadas

  • JavaScript
  • React Native
  • API REST
  • Express
  • SQLite

Objetivo do projeto

Criação de um app mobile para venda de pacotes de viagem através do consumo de APIs. Frontend foi desenvolvido tendo por objetivo a conclusão da disciplina de Desemvolvimento de Aplicativos Móveis. O backend foi desenvolvido com Node.js, Express e deploy na AWS para a conclusão do curso de Web Services. Foi utilizado também o Midllware de autenticação de usuários JWT.
