FitTrack

Aplicativo para organização de treinos e histórico de exercícios, utilizando React, Next.js, TypeScript e Supabase.

Funcionalidades do FitTrack

  • Sistema de cadastro, banco de dados e autenticação de usuários com Supabase.
  • Criação e gerenciamento de treinos personalizados pelo usuário.
  • Registro de histórico de treinos e exercícios para acompanhamento de progresso.
  • Interface intuitiva e responsiva para fácil navegação.
  • Busca de exercícios por parte do corpo e músculos trabalhados.
  • Integração com API de treinos e exercícios ExerciseDB.

Tecnologias Utilizadas

  • Typescript
  • Next.js
  • Consumo de API REST
  • Supabase

Vendas de Viagens

Sistema mobile de vendas e gerenciamento de pacotes de viagem.

Funcionalidades do app de Vendas de Viagens

  • Sistema de cadastro, banco de dados e autenticação de usuários JWT.
  • Criação, gerenciamento e compra de pacotes de viagem personalizados pelo nível de acesso de agente de viagens.
  • Sistema de compra e conversão de dinheiro e milhas.
  • Conversão de Cashback de milhas por compra
  • Criação de API REST própria e integração com API REST externa para criação de elementos de pacotes
  • Carteira simulando valores em dinheiro, milhas e histórico com data de depósitos e pagamentos por pacote do usuário.

Tecnologias Utilizadas

  • JavaScript
  • Next.js
  • Consumo de API
  • SQLite
