FitTrack

Aplicação web para gerenciamento de treinos personalizados, permitindo registrar exercícios, acompanhar progresso e organizar rotinas de forma simples.

Funcionalidades do FitTrack

  • Cadastro e autenticação de usuários
  • Criação e gerenciamento de treinos
  • Registro de histórico de exercícios
  • Interface moderna e intuitiva

Tecnologias Utilizadas

  • Typescript
  • Next.js
  • Consumo de API REST
  • Supabase

Objetivo do projeto

Desenvolvimento de uma aplicação web com foco em oferecer uma experiência de usuário moderna e eficiente para o gerenciamento de treinos personalizados. Futuramente pretendo expandir suas funcionalidades para criar uma comunidade de usuários conectados em uma rede social fitness.

Sistema de gerenciamento de Biblioteca

  • Criação e gerenciamento de livros.
  • Registro de histórico de aluguéis para acompanhamento de aluguel e devolução por parte dos usários.

  • Next.js
  • Consumo de API REST
  • Express

  • JavaScript

Objetivo do projeto

Criação de um projeto coletivo de gerenciamento de biblioteca completo com autenticação e autorização de múltiplos usuários com JWT como trabalho final da disciplina de Desenvolvimento Full Stack.

Vendas de Viagens

Sistema mobile de vendas e gerenciamento de pacotes de viagem.

Funcionalidades do app de Vendas de Viagens

  • Sistema de cadastro, banco de dados e autenticação de usuários JWT.
  • Criação, gerenciamento e compra de pacotes de viagem personalizados pelo nível de acesso de agente de viagens.
  • Sistema de compra e conversão de dinheiro e milhas.
  • Conversão de Cashback de milhas por compra
  • Criação de API REST própria e integração com API REST externa para criação de elementos de pacotes
  • Carteira simulando valores em dinheiro, milhas e histórico com data de depósitos e pagamentos por pacote do usuário.

Tecnologias Utilizadas

  • JavaScript
  • React Native
  • Consumo de API REST
  • Express
  • SQLite

Objetivo do projeto

Criação de um app mobile para venda de pacotes de viagem através do consumo de APIs. Frontend foi desenvolvido tendo por objetivo a conclusão da disciplina de Desemvolvimento de Aplicativos Móveis. O backend foi desenvolvido com Node.js, Express e deploy na AWS para a conclusão do curso de Web Services.
