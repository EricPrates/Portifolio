FitTrack

Aplicativo para organização de treinos e histórico de exercícios, utilizando React, Next.js, TypeScript e Supabase.

Funcionalidades do FitTrack

  • Sistema de cadastro, banco de dados e autenticação de usuários com Supabase.
  • Criação e gerenciamento de treinos personalizados.
  • Registro de histórico de exercícios para acompanhamento de progresso.
  • Interface intuitiva e responsiva para fácil navegação.

Tecnologias Utilizadas

  • Typescript
  • Next.js
  • Consumo de API
  • Supabase
