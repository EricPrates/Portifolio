#  Code Journey — Portfólio Eric Prates

![Portfolio Preview](https://portifolio-eric-prates.vercel.app/src/media/shotView.png)

Portfólio pessoal desenvolvido com HTML, CSS e JavaScript puro.  
Design responsivo com identidade visual própria, animações e vídeos dos projetos.

 **[portifolio-eric-prates.vercel.app](https://portifolio-eric-prates.vercel.app)**

---

##  Funcionalidades

- Seção **Sobre Mim** com stats, cards de especialidade e links
- **5 projetos** com vídeos demonstrativos em modal
- Cards expansíveis com tecnologias, funcionalidades e links
- Animações de scroll com **Intersection Observer**
- Navegação suave entre seções
- Design **totalmente responsivo** (mobile, tablet, desktop)
- **SEO** com Open Graph e Twitter Cards
